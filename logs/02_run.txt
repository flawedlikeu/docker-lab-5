$ docker run --name quad-default quadratic-solver
====================================================
 РОЗВ'ЯЗУВАЧ КВАДРАТНИХ РІВНЯНЬ  (варіант 5)
====================================================
 Коефіцієнти: a = 1, b = -3, c = 2
 Рівняння:    1x² - 3x + 2 = 0
----------------------------------------------------
 Крок 1. Дискримінант D = b² - 4ac
         D = (-3)² - 4·1·(2) = 9 - (8) = 1
 Крок 2. D = 1 > 0 — два різні дійсні корені.
         √D = 1
 Крок 3. x = (-b ± √D) / (2a)
         x₁ = (3 + 1) / 2 = 2
         x₂ = (3 - 1) / 2 = 1
 Відповідь: x₁ = 2, x₂ = 1
====================================================

$ docker run --name quad-two -e A=2 -e B=-7 -e C=3 quadratic-solver
====================================================
 РОЗВ'ЯЗУВАЧ КВАДРАТНИХ РІВНЯНЬ  (варіант 5)
====================================================
 Коефіцієнти: a = 2, b = -7, c = 3
 Рівняння:    2x² - 7x + 3 = 0
----------------------------------------------------
 Крок 1. Дискримінант D = b² - 4ac
         D = (-7)² - 4·2·(3) = 49 - (24) = 25
 Крок 2. D = 25 > 0 — два різні дійсні корені.
         √D = 5
 Крок 3. x = (-b ± √D) / (2a)
         x₁ = (7 + 5) / 4 = 3
         x₂ = (7 - 5) / 4 = 0.5
 Відповідь: x₁ = 3, x₂ = 0.5
====================================================

$ docker run --name quad-one -e A=1 -e B=2 -e C=1 quadratic-solver
====================================================
 РОЗВ'ЯЗУВАЧ КВАДРАТНИХ РІВНЯНЬ  (варіант 5)
====================================================
 Коефіцієнти: a = 1, b = 2, c = 1
 Рівняння:    1x² + 2x + 1 = 0
----------------------------------------------------
 Крок 1. Дискримінант D = b² - 4ac
         D = (2)² - 4·1·(1) = 4 - (4) = 0
 Крок 2. D = 0 — один (подвійний) корінь.
 Крок 3. x = -b / (2a) = -2 / 2 = -1
 Відповідь: x = -1
====================================================
