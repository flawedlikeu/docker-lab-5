$ docker run --name quad-none -e A=1 -e B=0 -e C=4 quadratic-solver
====================================================
 РОЗВ'ЯЗУВАЧ КВАДРАТНИХ РІВНЯНЬ  (варіант 5)
====================================================
 Коефіцієнти: a = 1, b = 0, c = 4
 Рівняння:    1x² + 0x + 4 = 0
----------------------------------------------------
 Крок 1. Дискримінант D = b² - 4ac
         D = (0)² - 4·1·(4) = 0 - (16) = -16
 Крок 2. D = -16 < 0 — дійсних коренів немає.
         (комплексні: x = 0 ± 2i)
 Відповідь: дійсних коренів немає.
====================================================

$ docker run --name quad-linear -e A=0 -e B=2 -e C=-4 quadratic-solver
====================================================
 РОЗВ'ЯЗУВАЧ КВАДРАТНИХ РІВНЯНЬ  (варіант 5)
====================================================
 Коефіцієнти: a = 0, b = 2, c = -4
 Рівняння:    0x² + 2x - 4 = 0
----------------------------------------------------
 Крок 1. a = 0, тому рівняння не квадратне, а лінійне:
         2x + (-4) = 0
 Крок 2. x = -c / b = -(-4) / 2 = 2
 Відповідь: x = 2
====================================================
